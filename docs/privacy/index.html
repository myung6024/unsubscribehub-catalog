해지링크 개인정보처리방침

현명준이 제공하는 Android 앱 해지링크(UnsubHub)에 적용됩니다. 시행일은 2026년 11월 10일입니다.

앱에서 처리하는 정보

해지링크는 구독 해지 안내를 제공합니다. 앱에 가입하거나 결제 정보를 입력할 필요가 없습니다. 서비스 검색어와 지원 서비스 앱의 설치 여부는 목록을 표시하는 데 기기에서 사용합니다. 설치된 앱만 보기 설정과 카탈로그 캐시는 기기에 저장되며 Android의 백업 설정에 따라 백업될 수 있습니다.

앱은 최신 가이드를 받기 위해 GitHub Pages에서 공개 카탈로그를 내려받습니다. GitHub는 서비스 보안을 위해 요청 IP 주소를 기록할 수 있습니다. 다른 서비스의 앱이나 웹사이트를 열면 해당 제공자의 개인정보처리방침이 적용됩니다. GitHub Pages의 데이터 처리 안내

사용 분석과 오류 진단

  • Google Analytics for Firebase는 앱 실행, 세션, 앱 버전, 기기 모델과 운영체제, IP 주소로 추정한 대략적인 지역, 앱 인스턴스 ID 및 사용 가능한 Android 광고 ID를 자동으로 처리할 수 있습니다. 개발자는 앱 사용을 파악하고 개선할 부분을 찾는 데 이 정보를 사용합니다.
  • Firebase Crashlytics와 관련 Firebase SDK는 비정상 종료 기록, 당시 앱과 기기의 상태, 세션 정보, Firebase 설치 ID 및 Crashlytics 설치 식별자를 처리할 수 있습니다. 개발자는 오류를 진단하고 앱 안정성을 개선하는 데 이 정보를 사용합니다.

이 정보는 Google LLC의 Firebase 및 Analytics 서비스로 암호화해 전송됩니다. 해당 서비스는 미국을 포함한 데이터센터 소재국에서 정보를 처리할 수 있습니다. Firebase 개인정보 보호 및 보안 · Google Analytics for Firebase 수집 안내

이메일 문의

서비스 추가 요청이나 오류 제보를 선택하면 이메일 앱에서 초안이 열립니다. 이메일을 보내면 개발자는 발신 주소와 사용자가 보낸 내용을 문의에 답하고 가이드를 개선하는 데 사용합니다. 문의에 필요한 내용만 보내 주세요.

UnsubHub Privacy Policy

This policy applies to the UnsubHub Android app, provided by 현명준 (LunaNim). It takes effect on November 10, 2026.

Information the app processes

UnsubHub provides subscription cancellation guides. You can use the app without creating an account or entering payment information. The app uses searches and checks whether supported service apps are installed on your device to display the list. It stores the installed-apps filter setting and a catalog cache on your device. Android may back up those files according to your backup settings.

The app downloads its public catalog from GitHub Pages. GitHub may log your IP address for security. If you open another service's app or website, that provider's privacy policy applies. GitHub Pages data processing

Usage analytics and crash diagnostics

  • Google Analytics for Firebase may automatically process app opens, sessions, app version, device model, operating system, approximate region inferred from IP address, app instance identifiers, and the Android advertising ID when available. The developer uses this information to understand and improve app usage.
  • Firebase Crashlytics and related Firebase SDKs may process crash records, app and device state, session information, Firebase installation IDs, and Crashlytics installation identifiers. The developer uses this information to diagnose problems and improve reliability.

This data is sent over encrypted connections to Firebase and Analytics services operated by Google LLC. These services may process information in countries where their data centers are located, including the United States. Firebase privacy and security · Google Analytics for Firebase data collection

Email support

When you request a guide or report an issue, the app opens a draft in your email app. If you send the message, the developer uses your sender address and message to respond and improve the guides. Include only information needed to handle your request.

Retention and deletion requests

Google Analytics keeps user and event data according to the retention setting of the linked property. Firebase Crashlytics keeps crash records and associated identifiers for 90 days before starting removal. Support email is retained as long as needed to handle the request and follow up, or longer where required by law. You can remove local settings and the catalog cache by clearing the app's data in Android settings. Google Analytics retention · Firebase retention
